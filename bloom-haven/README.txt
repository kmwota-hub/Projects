BLOOM HAVEN — CLIENT WEBSITE

1. Open index.html to preview the site.
2. Edit shop name/WhatsApp number in script.js at the top:
   const SHOP = { name: 'Bloom Haven', whatsapp: '254700000000' };
3. Also update the visible phone/location in index.html footer and the custom bouquet WhatsApp link.
4. Products, categories and prices are in the products array in script.js.
5. Product photos use Unsplash image URLs and require internet access. If a photo fails, the local hero image is shown automatically.
6. Cart is stored in the browser using localStorage, supports quantities/removal/clear, and creates a WhatsApp checkout message.
7. No backend or payment gateway is included. WhatsApp checkout is the ordering method.
