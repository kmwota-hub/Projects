EVERBLOOM — FULL MOBILE-FIRST ARTIFICIAL FLOWER SHOP

This build uses phone layout as the default CSS. Tablet and desktop layouts are progressive enhancements via min-width breakpoints.

MOBILE-FIRST FEATURES
- Designed first for 320px–430px phone screens
- Two-column touch-friendly product grid
- Horizontal swipe category/filter rows
- Sticky four-item bottom navigation
- Bottom-sheet shopping cart on phones
- Safe-area support for modern phones
- Large touch targets and full-width primary hero CTA
- No horizontal page overflow
- Responsive typography and product imagery
- Cart persists with localStorage
- Quantity + / −, remove and clear-cart controls
- WhatsApp order checkout with itemized order and subtotal
- Search and category filtering
- Menu closes after selecting a navigation link
- Background locks while mobile cart is open
- Escape-key cart close on keyboards
