PARADISE BOOK HUB — WEBSITE DEMO
=================================

This is a responsive front-end bookstore demonstration prepared for a proposed
KSh 15,000–20,000 starter website.

WHAT'S INCLUDED
---------------
- Responsive homepage for desktop, tablet and mobile
- Book catalogue with search and category filters
- Sample product cards and sample cover artwork generated in the page
- Add-to-bag cart and estimated total
- WhatsApp checkout flow (requires the real store number)
- Supplied bookstore shelf photo used in the design
- No paid backend or database required for this demo

IMPORTANT BEFORE SHOWING / LAUNCHING
------------------------------------
1. Open app.js.
2. Set STORE.whatsappNumber to the shop's WhatsApp number, e.g. "2547XXXXXXXX".
   Use country code 254, without +, spaces or dashes.
3. Replace the sample entries in the `books` array with real titles, authors,
   categories, prices and stock details confirmed by Paradise Book Hub.
4. Replace the sample cover artwork with approved book-cover images if the
   store provides them. Do not publish sample titles as real stock.
5. Confirm the business logo, contact details, delivery areas, delivery fees,
   payment methods, return policy and social links with the owner.
6. Get permission before using the store's official branding, photographs or
   product images publicly.

HOW TO PREVIEW
--------------
- Extract the ZIP.
- Open index.html in a browser.
- For a more reliable local preview, open the folder in VS Code and use the
  Live Server extension.

HOSTING
-------
This is a static website and can be hosted on Netlify, Vercel or Cloudflare Pages.
A custom domain, hosting setup, real catalogue entry and any future maintenance
should be agreed with the client and priced clearly.

SCOPE / HONEST DEMO NOTES
-------------------------
This package is a front-end sales demo, not a fully deployed production store.
It does not include an admin dashboard, database, user accounts, live inventory,
automated M-Pesa payments, delivery integration or order notifications to staff.
Those can be scoped as paid upgrades after the client's requirements are known.

The displayed KSh 350 prices are illustrative based on the information supplied
for the demo. Confirm exact prices and availability with the shop before launch.
