# Velvet Glow Salon Website
Production-ready static salon website.

## Before publishing
1. Open `script.js` and replace the WhatsApp number and business name in `SETTINGS`.
2. Open `index.html` and replace the displayed phone number, salon name, location and opening hours.
3. Replace service names/prices in `script.js`.
4. Replace remote sample image URLs with the client's own optimized photos for the final live site.
5. Replace sample testimonials with genuine client reviews before publishing.

## Run locally
Open `index.html` directly, or use VS Code Live Server.

## Publish
The folder is static and can be deployed directly to Vercel, Netlify, GitHub Pages, or normal shared hosting.
