# FixPoint Mobile Website
A responsive static website starter for a phone repair and accessories shop.

## Run
Open `index.html` directly, or use VS Code Live Server.

## Before client launch
1. Replace every `254700000000` / `0700 000 000` with the shop's real number.
2. Replace the placeholder location and opening hours.
3. Update demo products/prices in `js/products.js`.
4. Replace the placeholder email.
5. Add real product/shop photos if available.

## Deploy
Upload the folder to Netlify, Vercel, GitHub Pages, or any normal web host.
