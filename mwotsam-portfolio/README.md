# Mwotsam Tech Portfolio
Professional vanilla HTML/CSS/JavaScript portfolio.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Before publishing
1. Replace `your-email@example.com` in `index.html`.
2. Add your WhatsApp number to the `https://wa.me/` link using international format without + or spaces (example: https://wa.me/2547XXXXXXXX).
3. Replace/add project links and screenshots as your final assets become available.
4. Update project descriptions whenever needed.

## Structure
- `index.html` — content
- `css/style.css` — all responsive styling
- `js/main.js` — mobile navigation, header and reveal animation
- `images/` — ready for your real project/profile images
