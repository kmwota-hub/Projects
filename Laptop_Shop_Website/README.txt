NORTHSTAR COMPUTERS — LAPTOP SHOP WEBSITE STARTER
=================================================

A responsive, working front-end website intended as a KSh 15,000–20,000 starter
website package. Northstar Computers is a fictional demo brand. Product names,
specifications and prices are sample data only.

FEATURES
--------
- Responsive desktop, tablet and mobile layout
- Local product illustrations included in assets/
- Laptop catalogue with search
- Filters by use category and condition
- Sort by price
- Product detail pop-up
- Shopping cart with quantity controls and total
- WhatsApp order enquiry / checkout
- Business details and products editable in plain JavaScript
- No build tools, framework or database required

SET UP FOR A REAL CLIENT
------------------------
1. Edit config.js:
   businessName, whatsappNumber, phoneDisplay, location, openingHours, currency.
   WhatsApp number format: 2547XXXXXXXX (no +, spaces or dashes).

2. Edit products.js. Replace every demo item with the client's actual inventory,
   correct prices, exact specifications, condition and approved product photo.
   Product categories: Everyday, Business, Student, Creator, Gaming.
   Condition must be New or Refurbished.

3. Add product photos to assets/ and update each product's image path.
   Get permission to use the business logo, photos and other brand assets.

4. Confirm stock, price, warranty, returns, payment methods, delivery fees,
   delivery locations and business hours with the owner.

5. Test all product cards, search/filter, cart, WhatsApp checkout and mobile view.

PREVIEW
-------
Extract the ZIP and open index.html in a browser. For local development, open
the folder in VS Code and use the Live Server extension.

HOSTING
-------
Static site suitable for Netlify, Vercel or Cloudflare Pages. Connect the client's
domain after agreement and ensure the client owns the domain/hosting accounts.

PACKAGE SCOPE
-------------
Included: front-end catalogue, search/filter/sort, product details, cart and
WhatsApp checkout enquiry.
Not included: database, admin dashboard, live stock sync, customer accounts,
automated M-Pesa STK Push, payment reconciliation, delivery integration, SMS/email
notifications or order-management portal. Quote these separately if requested.

IMPORTANT
---------
The WhatsApp checkout sends an order enquiry; it does not collect payment or
reserve stock automatically. The shop must confirm availability and payment
details with the customer. Demo products/prices must not be presented as verified
live stock. This distinction should be clear in your client proposal.
