# Juja Spice Market Website

Ready-to-customize, mobile-first spice shop website.

## Before publishing
1. Replace every `254700000000` with the client's real WhatsApp/phone number in `index.html` and `script.js`.
2. Change "Juja Spice Market" to the client's business name.
3. Update products/prices in `script.js`.
4. Replace sample emoji product artwork with real client product photos when available.
5. Update location, delivery wording and contact information.

## Run locally
Open `index.html` directly, or use VS Code Live Server.

## Publish
Works as a static site on Vercel, Netlify or GitHub Pages.
